# TaskTracker — Gerenciador de Tarefas

## Descrição do Projeto

O TaskTracker é uma aplicação desenvolvida em Python para cadastrar e visualizar tarefas. Cada tarefa possui título, descrição, prioridade, data limite e status.

## Funcionalidades

- Cadastrar novas tarefas.
- Validar o preenchimento do título.
- Validar a prioridade da tarefa.
- Visualizar todas as tarefas cadastradas.
- Informar quando não existem tarefas cadastradas.
- Encerrar a aplicação pelo menu.

## Tecnologias Utilizadas

- Python 3
- Git
- GitHub

## Estrutura do Projeto

- `src/main.py`: código-fonte principal da aplicação.
- `docs/planejamento_logico.pdf`: planejamento lógico da Fase 1.
- `.gitignore`: arquivos ignorados pelo Git.

## Como Executar

1. Instale o Python 3.
2. Abra o terminal na pasta principal do projeto.
3. Execute o comando:

   `python src/main.py`

   No Windows, se necessário, utilize `py src/main.py`.
